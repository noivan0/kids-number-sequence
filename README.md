# 🌟 숫자 순서대로! (Kids Number Sequence Game)

유아(3~7세)를 위한 **숫자 순서 터치 게임**입니다.  
참고 이미지(D:\sample1.png)의 그리드 컨셉을 바탕으로, 아이가 숫자를 **순서대로 찾아 터치**하며 수의 크기와 단위 개념을 자연스럽게 익히도록 설계했습니다.

## ✨ 주요 특징

- **모바일 최적화**: 큰 터치 영역, 세이프에리어 대응, 2×2는 특히 거대한 버튼
- **1 ~ 99,999까지** 다양한 단위 지원 (1의 자리 → 10의 자리 → 100의 자리 → 1000의 자리)
- **10개의 기본 레벨** + **무작위 연습 모드**
  - 사용자가 요청한 정확한 예시 모두 포함:
    - 1-2-3-4 (2×2)
    - 10-20-30-40...
    - 11-12-13-...
    - 234-235-236-...
    - 1420-1520-1620-...
- **정확한 피드백**: 맞으면 초록색 + 애니메이션 + 한국어 음성, 틀리면 빨간색 흔들림
- **힌트 기능**: "도와줘!" 버튼으로 다음 정답 살짝 강조
- **완전한 한국어 음성** (Web Speech API)
- **설치 가능 웹앱** (PWA): 홈 화면에 추가해서 진짜 앱처럼 사용 가능

## 🚀 실행 방법

1. `index.html` 파일을 **크롬/사파리/엣지**에서 열기
2. (권장) 간단한 로컬 서버로 실행:
   ```bash
   cd /mnt/d/kids-number-sequence
   python3 -m http.server 8080
   ```
   그 후 `http://localhost:8080` 접속

3. 모바일 기기에서 테스트하려면 같은 네트워크에서 접속하거나, `ngrok` 등을 사용하세요.

## 📱 앱으로 설치하기 (PWA)

- 크롬/엣지 주소창 오른쪽에 **설치 아이콘**이 나타납니다.
- 또는 "앱 설치" 배너가 뜨면 추가하세요.
- 설치 후에는 오프라인에서도 사용 가능하고, 더 큰 화면으로 즐길 수 있습니다.

## 🎮 플레이 방법

1. 홈 화면에서 원하는 난이도(레벨)를 선택
2. 화면 상단에 표시된 **"다음 숫자"**를 확인
3. 아래 격자에서 그 숫자를 찾아 **터치**
4. 모든 숫자를 순서대로 찾으면 축하 애니메이션 + 칭찬

**힌트**: 노란색 "도와줘!" 버튼을 누르면 다음 정답이 반짝입니다. (너무 자주 쓰지 않도록!)

## 🛠️ 고급 기능 (부모/선생님용)

브라우저 콘솔(F12)에서 직접 커스텀 레벨을 만들 수 있습니다:

```js
// 예: 500부터 10씩 8개, 3×3 격자
createCustomLevel(500, 8, 10, 3);

// 예: 98760부터 1씩 6개 (매우 큰 수 연습)
createCustomLevel(98760, 6, 1, 3);
```

## 🧠 교육적 의도

- **수의 크기 감각** : 4와 1420의 차이를 시각적으로 체감
- **자릿값/단위 개념** : 10씩, 100씩 뛰는 패턴을 반복 체험
- **순서와 규칙성** : 오름차순 규칙을 몸으로 익힘
- **실패에 대한 두려움 ZERO** : 틀려도 부드럽게 안내, 무한 재시도
