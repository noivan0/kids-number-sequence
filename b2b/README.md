# B2B 자료 패키지 (숫자 순서대로!)

이 폴더에는 실제로 유치원·어린이집에 보낼 수 있는 자료들이 들어 있습니다.

## 📄 포함 파일

### 1. B2B_제안서_숫자순서대로_v1.html
- **1페이지 제안서** (A4 최적화)
- 사용법:
  1. Chrome 또는 Edge로 열기
  2. `Ctrl + P` (인쇄)
  3. "대상"에서 **"PDF로 저장"** 또는 "Microsoft Print to PDF" 선택
  4. 여백을 "최소"로 설정하고 저장
- 인쇄 결과가 매우 깔끔하고 전문적으로 나옵니다.

### 2. 워크시트_샘플_10씩더하고빼기_v1.html
- **2페이지 구성** (학생용 활동지 1장 + 선생님 가이드 1장)
- Phase 2-D "10씩 더하고 빼기"와 완벽 연계
- 실제 수업에서 바로 사용 가능
- 인쇄 방법은 위와 동일

## 사용 추천 방법

1. **먼저 제안서 PDF를 10~20부 출력**
2. 관심 있는 유치원/어린이집 리스트업 (원장 + 담임교사 이름 확인)
3. 제안서 + 워크시트 샘플 2장을 함께 넣어서 방문 or 우편/이메일
4. "30분만 시간을 내주시면 직접 시연해드리겠습니다" 문구 강조
