3~7세 아이를 위한 수 개념 규칙 발견 게임  |  Phase 1~4 완전 무료

1. 현장에서 느끼는 실제 어려움
  • 아이들 수 개념 수준 차이가 너무 커서 개별 지도가 어렵습니다.
  • 학부모 상담 때 “집에서 어떻게 도와주면 좋을까요?”에 구체적인 답을 주기 어렵습니다.
  • 기존 앱들은 광고가 많거나 교육적 효과를 설명하기 애매합니다.
2. 우리가 제공하는 해결책
아이가 스스로 규칙을 발견하도록 설계된 교육 게임입니다.
1씩 → 2씩 → 5씩 → 10씩 → 100씩… 아이가 직접 패턴을 찾아가며 10의 자리와 큰 수 감각을 체득합니다.
총 22개 트랙 (Phase 1~4) 모두 무료 제공
3. 도입하면 얻는 효과
아이에게
지루한 반복이 아닌 ‘스스로 발견하는 재미’. 20분만으로도 수 개념이 눈에 띄게 좋아집니다.
선생님에게
아이별 진행 상황을 한눈에 파악. 학부모 상담 때 객관적인 자료로 활용 가능합니다.
학부모에게
광고 없는 깨끗한 환경 + 구체적인 학습 리포트로 “우리 아이가 잘하고 있나?” 불안을 해소합니다.
4. 도입 절차 (매우 간단합니다)
  1. 30분 무료 시연 (원하시는 시간에 방문 또는 온라인)
  2. 2주간 무료 체험 (1개 반 전체 사용 가능, 데이터 제공)
  3. 체험 후 피드백 → 정식 도입 결정
  4. 간단한 계약 후 바로 사용 시작
5. B2B 도입 비용 (2026년 기준)
구분 월 요금 제공 내용
유치원 1반 (최대 25명) 15,000원 교사용 대시보드 + 학부모 리포트 공유
어린이집 1개 학급 15,000원 위와 동일 + 인쇄용 워크시트 무제한
3반 이상 기관 협의 (할인 적용) 전체 데이터 분석 + 맞춤 자료 + 교사 연수
